# 量化交易金融知识手册

本文档用通俗语言解释本项目涉及的金融和量化术语，供非专业背景的使用者参考。每个术语首次出现在其他文档时，应在此处有对应条目。

---

## 一、K线基础

### K线（Candlestick / Bar）
每根K线代表一段时间内价格变化的"总结"。一根K线有四个核心数据：
- **开盘价（Open）**：这段时间第一笔成交的价格
- **最高价（High）**：这段时间内最高成交价
- **最低价（Low）**：这段时间内最低成交价
- **收盘价（Close）**：这段时间最后一笔成交价格

K线的"时间跨度"决定它代表多长时间：5分钟K线 = 每根线代表5分钟内的价格行为；日K线 = 每根线代表一整个交易日。

### 成交量（Volume）
这段时间内总共成交了多少"手"（份额）。成交量是价格行为的"信心度"——同样幅度的上涨，成交量大代表很多人愿意在这个价格买入，说服力更强；成交量小则可能只是少数人推价，容易反转。

### 多时间框架分析（Multi-Timeframe Analysis）
同时看多个时间周期的K线，用大周期判断方向、小周期找入场点：
- **日线**：判断大趋势（这只股票整体在涨还是跌）
- **2小时线**：判断中期节奏（今天或这几天的走势节奏）
- **15分钟线**：寻找具体的买卖机会区域
- **5分钟线**：精确控制买入/卖出的时机

## 二、趋势与均线

### 趋势（Trend）
价格整体的运动方向：
- **上升趋势（Uptrend）**：价格一波比一波高，低点也比低点高——适合持仓做T
- **下降趋势（Downtrend）**：价格一波比一波低——应减仓观望
- **震荡（Neutral / Sideways）**：价格在一个范围内来回波动，没有明确方向

### 均线（Moving Average，简称MA）
把过去N天的收盘价加起来求平均，每天计算一次，连成一条线。均线能平滑价格的短期噪音，让趋势更清晰。

常用均线：
- **MA5**（5日均线）：代表最近一周的平均价格，反应最快
- **MA10**（10日均线）：反应中等速度
- **MA20**（20日均线）：代表近一个月的平均，是重要的趋势参考线

**判断趋势的简单规则：**
```
收盘价 > MA5 > MA10 > MA20  →  强上升趋势，均线多头排列
收盘价 < MA10，或 MA5 < MA10  →  趋势破坏，暂停买入
```

### 均线金叉 / 死叉
- **金叉**：短期均线从下往上穿过长期均线（看涨信号）
- **死叉**：短期均线从上往下穿过长期均线（看跌信号）

## 三、核心指标

### VWAP（成交量加权平均价）
全称：Volume Weighted Average Price。

**通俗解释**：把今天每笔成交的价格，按照那笔成交的"体量"来加权平均。成交量大的价格对VWAP影响更大，所以VWAP更能反映市场上大多数资金的"平均成本"。

**用法**：
- 价格在VWAP之上 → 今天买入的人整体赚钱 → 市场情绪偏多
- 价格在VWAP之下 → 今天买入的人整体亏钱 → 市场情绪偏空
- 回踩VWAP后反弹收复 → 主力成本区获得支撑，是做T买入的信号

**重要细节**：VWAP每个交易日开盘时重置，不能跨日累计计算。

### MACD（指数平滑异同移动平均线）
全称：Moving Average Convergence Divergence。

**通俗解释**：MACD其实在测量"短期均线和长期均线之间的距离"，以及这个距离在变大还是变小。

三个组成部分：
- **MACD线（快线）**：12日EMA减去26日EMA的差值
- **信号线（慢线）**：MACD线的9日EMA
- **柱状图（Histogram）**：MACD线与信号线的差，正值为红柱，负值为绿柱

**用法**：
- 柱状图从负转正，或MACD线从下往上穿越信号线（金叉）→ 短期动量转多，可能是趋势转折
- 柱状图持续为正且在增大 → 上升趋势强劲
- 价格创新高但MACD不创新高（顶背离）→ 动量衰竭，注意回调

> EMA（指数移动平均）= 比普通均线给近期价格更高权重的平均，反应更快。

### KDJ（随机震荡指标）
**通俗解释**：KDJ测量"当前价格在最近N天高低区间中的相对位置"，判断是否超买或超卖。

三条线：
- **K线**：快速线，反应灵敏
- **D线**：K线的平滑，相对稳定
- **J线**：K和D的衍生，最极端，容易超买超卖

**数值含义（0-100范围）**：
- **J值 > 80**：超买区域，价格涨得过快，短期可能回调
- **J值 < 20**：超卖区域，价格跌得过多，短期可能反弹
- **KD金叉（K从下往上穿D）**：短期买入信号
- **KD死叉（K从上往下穿D）**：短期卖出信号

**最佳用法**：在上升趋势里，等KDJ回调到低位再金叉时买入，比高位追入安全得多。

### ATR（平均真实波动幅度）
全称：Average True Range。

**通俗解释**：衡量一只股票"平均每天能波动多大"。波动大的股票ATR高，波动小的ATR低。

**用法**：
- ATR% < 1.8%：股票今天波动太小，不够做T，信号没意义
- ATR% > 3%：波动充分，适合日内做T
- **止盈止损设置**：专业做法是把止损设为ATR的1.5~2倍，而不是固定百分比——波动大的股票需要给更大的空间，不然容易被随机噪音洗出局

### 动量/涨速（Momentum / Rate of Change，ROC）
**通俗解释**：价格涨或跌的"速度"。同样是涨5%，如果是用一根K线涨的说明动能强，如果是用100根K线慢慢涨的，动能就弱。

**用法**：
- 成交量放大 + 价格快速上涨 = 强势动量，可能继续追高
- 价格涨但涨速越来越慢 = 动量衰竭，注意风险

## 四、交易模式

### 核心仓（Core Position）
长期持有、不频繁交易的主仓位。目的是吃到标的本身的涨幅。本项目中默认占总资金的70%，只在趋势彻底走坏时才逐步减仓。

### T仓（T-Trade Position）
在核心仓基础上，用剩余资金做日内或短期波段交易的仓位。本项目中默认占总资金的30%。T仓的目的是通过高买低卖（或低买高卖）额外赚取差价，降低核心仓的平均持仓成本。

### 做T（T+0 Day Trading）
在持有核心仓的同时，用T仓资金在日内"低买高卖"：
- 早上低位买入T仓
- 日内高位卖出T仓
- 核心仓不动，T仓完成一次"来回"

**注意**：A股是T+1结算（当天买不能当天卖），所以正规做T是"先卖后买"（用昨天的底仓卖出，低位补回来）。美股是T+0，当天买可以当天卖，但受PDT规则约束（见下方）。

### 冲高回落（Surge and Retreat）
价格快速拉升到高位后，随即快速下跌回来。这种情况通常意味着：高位有大量卖出压力，买入力量不够支撑价格。

**做T含义**：这是T仓卖出的信号——价格冲高时卖掉T仓，等回落后再择机买回。

### 低开冲高（Gap Down Then Push）
开盘价比前一天收盘低（低开），但随后价格快速上涨。

**做T含义**：低开制造了一个短期恐慌盘，主力趁机洗盘后拉升。低开的低点是买入T仓的机会，等拉升后卖出。

### 回踩（Pullback）
在上升趋势中，价格短暂回调（但不跌破趋势），之后重新恢复上涨。健康的上升趋势会有规律性的回踩——是买入的机会，不是恐慌的理由。

### 收复VWAP（Reclaim VWAP）
价格从VWAP下方回到VWAP上方。意味着今天买入的平均成本线重新被站上，多头重新取得优势。这是本项目核心买入信号之一。

## 五、风险管理

### 止盈（Take Profit）
提前设定的卖出目标价。当T仓盈利达到目标时自动卖出，锁定利润。

### 止损（Stop Loss）
提前设定的最大亏损阈值。当T仓亏损达到此限额时强制卖出，避免损失继续扩大。

**关键原则**：止损不是"认错"，是风险管理的必要工具。没有止损的策略，一次大跌可以吃掉之前所有的盈利。

### 动态止盈（Dynamic Take Profit）
止盈目标不固定，而是根据仓位层数（加了几次仓）来动态调整：
- 1层T仓：目标1.8%（标准要求）
- 2层T仓：目标1.4%（加过一次仓，降低要求，更容易出场）
- 3层及以上：目标1.0%（摊得更多，尽快锁利）

### 仓位管理（Position Sizing）
决定每次买入用多少钱。专业做法不是"每次都买固定金额"，而是根据：
- 信号的确信度（Confidence）
- 当前波动率（ATR）
- 已有持仓风险

来动态计算每次应该买多少。

### 加仓网格（Grid Buying / Averaging Down）
价格下跌时分批买入，摊低平均成本。看起来聪明，但有巨大风险：如果价格单边下跌，你会越跌越买，最终弹药耗尽，被迫在亏损最大时止损。**加仓必须有明确的最大层数限制。**

### 最大回撤（Max Drawdown）
从某个历史最高点到随后最低点的最大跌幅。衡量策略或账户"最惨的时候亏了多少"。评估策略时，最大回撤比总收益更重要——因为它直接考验你的心理承受能力和资金安全边际。

## 六、量化概念

### 回测（Backtesting）
把策略逻辑应用到历史数据上，模拟"如果当时用这个策略，结果会怎样"。

**重要限制**：
- 回测结果≠未来表现
- 过拟合（在历史数据上调参太精细）会让回测看起来很好，但实盘一塌糊涂
- 必须同时做样本内测试（调参用的数据）和样本外验证（没用过的新数据）

### 前视偏差（Look-Ahead Bias）
在回测中，"不小心"用了交易时实际上还不知道的信息。比如：用K线收盘价产生信号，但同时假设在这根K线收盘价成交——现实中你只有等K线收盘才知道收盘价，成交只能在下一根K线开盘。前视偏差会让回测收益虚高，是最常见的回测错误之一。

### 滑点（Slippage）
你想以A价格成交，但实际成交价是A+一点点（买入时吃亏）或A-一点点（卖出时吃亏）。原因是下单到成交之间市场在变化。本项目默认模拟0.3%的滑点。

### Alpha（超额收益）
你的策略相对于"什么都不做只持有"多赚了多少。如果持有SPCX涨了10%，你的核心+T策略赚了12%，Alpha = 2%。

**关键问题**：做T产生的手续费+滑点，到底有没有被Alpha覆盖？这是验证做T是否有价值的核心问题。

### PDT规则（Pattern Day Trader Rule）
美国证券法规：在保证金账户中，如果5个交易日内进行4次以上"当天买当天卖同一只股票"的操作，且账户净值低于2.5万美元，会被标记为"Pattern Day Trader"并限制交易。对小资金账户影响很大。

### 过拟合（Overfitting）
在历史数据上把策略参数调得"太完美"，导致策略实际上是在"背诵历史答案"而不是发现真正的规律。判断是否过拟合的方法：在训练数据之外的新数据上测试，如果表现大幅下降，说明已经过拟合。

## 七、涨速与形态

### 涨速速率（Price Velocity / Rate of Change）
单位时间内价格变化的幅度。5分钟内涨了3%，涨速很快；一天涨了0.1%，涨速很慢。

**用法**：结合成交量判断：
- 涨速快 + 成交量大 = 有效突破，可以跟进
- 涨速快 + 成交量小 = 假突破，容易回踩

### 趋势走坏（Trend Breakdown）
上升趋势结束的信号，常见判断标准：
- 收盘价跌破20日均线且成交量放大
- MA5下穿MA10（短期均线死叉）
- MACD在日线级别出现顶背离后死叉

**逐步清仓策略**：不要等趋势完全确认才出货，可以分批减仓：
- 第一次信号出现时减掉T仓的三分之一
- 第二次确认信号时再减三分之一
- 明确破位时清掉剩余T仓，核心仓根据整体趋势判断是否保留

## 八、本项目交易标的

### SPCX 与 SPCXB

**SPCX**：美国股票市场（纳斯达克）上市的 ETF，追踪商业航天相关公司（SpaceX、火箭发射、卫星通信产业链等）。全称 Procure Space ETF，代码 SPCX。

**SPCXB/USDT**：SPCX 在币安交易所的"代币化版本"（B-Stock）。用 USDT 就能交易，价格锚定底层 SPCX 股票，1单位 SPCXB ≈ 1股 SPCX。本项目当前实盘的主要标的。

### B-Stock（币安代币化股票）

**通俗解释**：币安和持牌金融机构合作，把美股"影印"成一种代币放在币安上交易。你买的 SPCXB 背后有真实的 SPCX 股票作为抵押，价格跟底层股票挂钩。

**优点**：
- 不需要美股账户，用币安账号就能交易
- 不受 PDT 规则限制（见"结算规则"条目），可以无限制当日来回做 T
- 即时结算（T+0），买了马上可以卖

**注意点**：
- 流动性比直接在纳斯达克买卖 SPCX 低，挂单深度浅，大单容易造成较大滑点
- 活跃交易时段集中在美股开盘时间（北京时间 21:30～次日 4:00，夏令时 22:30），其他时间几乎无量
- Binance 可能根据监管要求暂停或下架 B-Stock，存在平台政策风险

## 九、本项目特有概念

### 信号（Signal）
策略逻辑输出的"操作指令"。本项目信号只有三种：
- **BUY**：T仓买入
- **SELL**：T仓卖出（全部）
- **HOLD**：不操作，等待

### 置信度（Confidence）
策略对当前信号的"把握程度"，0到1之间。数值越高代表这个信号的质量越好。**当前代码虽然计算了置信度，但还没有用它来影响仓位大小**——这是待优化项。

### 风险事件（Risk Event）
信号本来想成交，但被执行层拒绝的记录。常见原因：
- `spread_rejected`：买卖价差太大（流动性不好）
- `grid_spacing_rejected`：距离上次买入价格太近，不满足加仓间距

### 订单意图（Order Intent）
策略生成的下单计划，包含：买/卖方向、数量、原因、是否为模拟单（paperOnly）。
